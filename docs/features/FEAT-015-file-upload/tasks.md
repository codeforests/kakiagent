## Implementation notes

- **T6/T7 order:** the fixtures (T7) were committed just before the adapters (T6), whose integration tests read them.
- **OCR fixtures use a hyphen:** with `eng+chi_sim`, Tesseract reads a lone em dash between Latin words as 一. The text-layer fixtures keep the em dash; the OCR'd ones (`scanned-menu.pdf`, `menu-photo.*`) use ` - `, which the fake extractor accepts too. A real model reads either.
- **S3 endpoint (design §5.8):** the worker (and the API in T9) use the existing `AWS_ENDPOINT_URL` for LocalStack, as the scheduler's anchor store does, rather than a new `S3_ENDPOINT_URL`.
- **Job outcome:** `runIngestJob`'s outcome gains `type` (scan → parse) and `signature` (malware), so the worker logs them; neither is audited (NFR-11).
- **T8 evidence:** on the local stack, `price-list.pdf` and `scanned-menu.pdf` put into `kaki-local-quarantine` with a source created through `createFileSource` ran scan → parse → extract → promote to `ready` in the dev worker (3 pages and 7 facts; 2 OCR pages and 4 facts). `/readyz` reports `{"database":true,"browser":true,"scanner":true,"ocr":true}`. clamd accepts a 25 MB stream. The image build couldn't run here (the sandbox's TLS proxy isn't trusted inside `docker build`, and Docker Hub rate-limited the base image), so CI builds the ingest-worker image and checks its Tesseract languages (T10).
- **T9 evidence:** `apps/api/test/uploads.int.test.ts` (49 tests) covers every designed success and error of `POST /kb/uploads` and the file body of `POST /kb/sources`, the list's limits, OCR confidence on pages, retry (`not_retryable` for each D7 failure; `scan` or `parse` restarts) and the purge job on delete. A PUT to a real presigned URL on LocalStack stores the object at `uploads/<session tenant>/<uploadId>`. The URL signs `content-length;content-type;host`; LocalStack doesn't enforce signed headers (S3 does), so the refused-wrong-length half is asserted on the signature, and the worker re-checks the stored size (§5.3). The `UploadSigner` interface lives in `server.ts` beside `Deps`, which keeps the module graph acyclic.
- **T10 evidence:** `terraform fmt -check -recursive`, `validate` and `terraform test` (2 runs, with new assertions for the malware protection plan, upload CORS, both tasks' environment and policies) pass on Terraform 1.16.6 with the locked providers (installed from releases.hashicorp.com, as the registry is blocked here); `actionlint` 1.7.12 is clean; Trivy (misconfig and secrets) finds nothing. Two additions to design §5.8: both tasks' file policies include `s3:ListBucket` on quarantine too, so a missing upload answers 404 (`upload_missing`) rather than 403; and the copy to `sources` replaces tags (`TaggingDirective: REPLACE`), so the worker needs no tagging permission there. The quarantine lifecycle expiry drops from 7 days to 1, as §5.3 says. CI's security job now also builds the ingest-worker image and checks its Tesseract languages and pdftoppm (the T8 image half).
- **T12 evidence:** `pnpm --filter @kaki/dashboard build`, typecheck and lint pass. On the running stack, screenshots at 1280 px and 390 px of SCR-APP-023 (empty, file rows), SCR-APP-007 (default, refused, uploading, added and ready), SCR-APP-024 (a PDF, a PowerPoint with "Slides", an image with no page list and "1 read with OCR"; a malware failure with "Upload again"), SCR-APP-028 ("From page 1 of price-list.pdf") and the review card ("page 1 of price-list.pdf", "File · read") match ui-design.md. The fact page reads the file's name from the sources list, and says "the file" for a role that can't list sources. The local API now gets LocalStack's test credentials from `gen-local-env.mjs`, as the workers do, so it can sign upload URLs.
- **T13 evidence:** `e2e/tests/files.e2e.ts` passes in Chromium against the local stack (2 tests): a 26 MB file refused before any upload request; a PDF and a photo uploaded with a visible progress bar (the PUT is held 1.5 s by a route), both to Ready; file rows, the PDF's three pages with no links, a fact's "From page 1 of price-list.pdf", the photo's OCR count; an EICAR file failing as malware with "Upload again", no Retry and no pages; axe on the three screens. `sources.e2e.ts` (FEAT-012) follows the renamed "Add sources" link and heading and still passes.
- **Unit test speed:** `parse.test.ts`'s zip-bomb case built its 100 MB entry with fflate's JavaScript deflate, which passed alone but timed out when the whole suite ran in parallel and under coverage. The case now builds the same one-entry ZIP (a real 100 MB + 1 byte entry) with Node's zlib in about 0.2 s; its assertions are unchanged.
