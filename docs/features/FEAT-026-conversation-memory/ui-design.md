# UI design: FEAT-026 — Conversation memory and summarisation

> Screens: none · Status: designed · 2026-11-11

The plan lists no screen for this feature ("visible in answers", plan §4 FEAT-026). Visitors see the effect only in replies: the agent keeps using the name, items, quantities and dates they gave earlier, in the widget and after a handoff to Telegram or email (SCR-WGT-002's reply bubbles, unchanged). Staff see the same replies in the thread (SCR-APP-015, unchanged). No component, copy, state or token changes, and no entries in `docs/design-manifest.json`.
